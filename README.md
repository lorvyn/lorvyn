## English

> This repository is the **official release channel** of Lorvyn. It contains installers and release notes only, not the application source code.

### What is Lorvyn

Lorvyn is a lightweight desktop workspace for folders and code: an editor, a terminal and an AI assistant in one window.

- **Editor.** Open any folder and edit files with syntax highlighting.
- **Terminal.** Built-in terminal next to your code.
- **AI assistant.** Ask it to explain, fix or write code without leaving the window. Choose between **GPT-6.1 Sol** and **DeepSeek V4.1 Flash**.
- **Themes.** Black and white style, dark and light themes.
- **Languages.** English and Russian interface.
- **Free plan.** 50 requests per 5 hours and 100 requests per week.

### Download

Get the latest installer from the **[Releases](https://github.com/lorvyn/lorvyn/releases/latest)** page, or from the [website](https://lorvyn.vercel.app).

| File | Description |
|---|---|
| `Lorvyn-Setup-<version>-x64.exe` | Windows installer (recommended) |
| `Lorvyn-<version>-win-x64.zip` | Portable build, no installation |

> The installer is not code-signed yet, so Windows SmartScreen may show a warning. Choose **More info, Run anyway**.

### Updates

New versions are published here as [GitHub Releases](https://github.com/lorvyn/lorvyn/releases). Every release has release notes in **English and Russian**.

The installed app checks for updates itself: open **Settings → Updates** and press **Check for updates**. When a new version is found, the app shows its notes and downloads it on your confirmation. The portable build does not update itself.

News and status messages are also posted in Telegram: **[@LorvynNews](https://t.me/LorvynNews)**.

### Changelog

### A note about errors

Lorvyn is in beta. If you see an AI error, it most likely means the AI balance has run out. We are topping it up as fast as we can. Status updates are in [Telegram](https://t.me/LorvynNews).

## Русский

> Этот репозиторий — **официальный канал релизов** Lorvyn. Здесь только установщики и описание обновлений, без исходного кода приложения.

### Что такое Lorvyn

Lorvyn — лёгкое десктопное рабочее место для папок и кода: редактор, терминал и ИИ-ассистент в одном окне.

- **Редактор.** Откройте любую папку и правьте файлы с подсветкой синтаксиса.
- **Терминал.** Встроенный терминал рядом с кодом.
- **ИИ-ассистент.** Просите объяснить, исправить или написать код, не выходя из окна. Доступны **GPT-6.1 Sol** и **DeepSeek V4.1 Flash**.
- **Темы.** Чёрно-белое оформление, тёмная и светлая темы.
- **Языки.** Интерфейс на русском и английском.
- **Бесплатный план.** 50 запросов за 5 часов и 100 запросов в неделю.

### Скачать

Последний установщик лежит на странице **[Releases](https://github.com/lorvyn/lorvyn/releases/latest)**, а также на [сайте](https://lorvyn.vercel.app).

| Файл | Описание |
|---|---|
| `Lorvyn-Setup-<версия>-x64.exe` | Установщик для Windows (рекомендуется) |
| `Lorvyn-<версия>-win-x64.zip` | Портативная версия, установка не нужна |

> Установщик пока не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение. Нажмите **Подробнее, Выполнить в любом случае**.

### Обновления

Новые версии выходят здесь как [GitHub Releases](https://github.com/lorvyn/lorvyn/releases). У каждого релиза есть описание на **русском и английском**.

Установленное приложение проверяет обновления само: откройте **Настройки → Обновления** и нажмите **Проверить обновления**. Когда найдена новая версия, приложение покажет описание и скачает её после вашего подтверждения. Портативная версия сама не обновляется.

Новости и статус также публикуются в Telegram: **[@LorvynNews](https://t.me/LorvynNews)**.

### История изменений
